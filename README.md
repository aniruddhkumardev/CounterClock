## ✨ Features

| Feature | Description |
|---------|-------------|
| 🌓 **Dark / Light Mode** | Smooth toggle with animated switch — adapts to your preference |
| 🕐 **Live Clock** | Real-time clock with seconds, updates every second |
| 🧮 **Interactive Counter** | Increment/decrement with buttons or keyboard shortcuts |
| ⌨️ **Keyboard Shortcuts** | `↑` `↓` for counter, `R` to reset, `T` to toggle theme |
| 🎨 **Glassmorphism UI** | Modern frosted-glass effect with animated gradient border |
| 📱 **Responsive Design** | Works seamlessly on desktop, tablet, and mobile |
| ⚡ **Pure Vanilla** | No frameworks or libraries — just HTML, CSS, and JavaScript |
| 🎯 **Accessible** | Keyboard-friendly with focus states and ARIA-ready |
